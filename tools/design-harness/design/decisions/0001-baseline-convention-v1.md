# ADR-0001: 도입 시점 기준선 — 규약 v1

- **상태**: Accepted
- **날짜**: 2026-10-17
- **관련 요구사항**: R-001 ~ R-007
- **대체하는 것**: 없음
- **제안 계기**: 사전 설계

## 맥락

design-harness 규약 v1은 pray-everyday 저장소에서 대화를 거치며 만들어졌고, 이미 `design/harness/`에 구현돼 있다.
그 과정의 중간 결정들을 ADR로 소급해 만들지 않고, 이 스코프를 만든 시점의 규약 전체를 기준선 하나로 등록한다.
이후의 변경은 이 기준선에서 출발하는 ADR로 기록한다.

## 결정

ARCHITECTURE.md의 D-01 ~ D-08을 현재 결정으로 등록한다. 요약:

- **D-01** 구속력은 현재 상태 문서에만, ADR은 이유의 기록
- **D-02** 디렉터리 기반 스코프 계층과 체인 읽기
- **D-03** 폐기 즉시 archive, 레거시 모방 금지
- **D-04** 파일 소유권 3분류와 관리 블록
- **D-05** `harness.toml`의 규약 버전과 일치 검사
- **D-06** `AGENTS.md`와 git hook 중심의 도구 중립 전달, 어댑터는 얇게
- **D-07** 검사기는 구조만, 의미는 리뷰 체크리스트
- **D-08** 저장소 안에 둔 표준 라이브러리 Python 스크립트 하나

## 검토한 대안

기준선 등록이라 별도 대안을 비교하지 않았다. 각 결정을 정할 때 검토한 대안은 git 이력의 커밋 메시지에 있다.

## ARCHITECTURE.md 반영안

반영 완료. D-01 ~ D-08의 가정, 한계, 재검토 트리거는 ARCHITECTURE.md의 결정 표를 따른다.
