# ADR-0008: 미리보기 배포를 Vercel과 Neon의 무료 등급으로

- **상태**: Accepted
- **날짜**: 2026-10-24
- **대체하는 것**: 없음
- **관련**: 기술 스택과 실행 환경, API 계약, 계정과 인증, 데이터 원본과 동기화

## 요약

개발 중인 버전을 URL로 보여 주는 미리보기 환경을 비용 없이 Vercel(Hobby)과 Neon(Free)에 둔다. 웹과 서버는 Vercel의 별도 프로젝트로 배포하고, 웹 프로젝트가 `/api/*`를 서버 프로젝트로 넘겨(외부 rewrite) 브라우저에는 한 출처로 보이게 한다. 서버 코드는 서버리스와 상시 실행 서버 양쪽에서 돌게 써서, 운영으로 넘어갈 때는 배포 방식만 바꾼다.

## 맥락

서비스는 기획과 개발 단계이고 운영 시기와 수익 모델이 정해지지 않아, 배포에 비용을 쓰지 않으려 한다. 그래도 개발 중인 버전을 사용자 본인과 가족 등 몇 사람이 URL로 써 볼 수 있어야 한다. 로그인은 카카오·구글 로그인을 먼저 만든 뒤 배포한다(개발용 로그인은 운영 설정에서 켜지지 않는다, ADR-0005).
세션은 HttpOnly 쿠키(SameSite=Lax)이고 웹은 `/api`로 서버를 부른다. 웹과 서버가 서로 다른 사이트(예: 각자의 플랫폼 기본 도메인)에 있으면 세션 쿠키가 서드파티 쿠키가 되어 브라우저가 막으므로, 브라우저에는 한 출처로 보여야 한다. 서버 DB는 PostgreSQL 18 이상이 필요하다(`uuidv7()`).
결정 시점의 조건: Vercel Hobby는 무료이고 비상업용이며 함수 리전을 하나 고를 수 있다. Neon Free는 프로젝트마다 월 100 CU-시간과 1GB를 주고 5분 쉬면 잠든다. 아시아 리전은 Neon이 싱가포르와 시드니, Vercel 함수는 서울과 싱가포르 등이다.

## 결정

- **웹**: Vercel 프로젝트(루트 `apps/web`)로 SPA 정적 파일을 배포한다. `/api/:path*`를 서버 프로젝트의 주소 `/:path*`로 넘기는 rewrite를 둔다(접두사를 떼므로 서버 경로와 명세의 `servers` 경로는 지금처럼 접두사가 없다)
- **서버**: Vercel 프로젝트(루트 `apps/server`)로 NestJS를 함수로 배포한다. 함수 리전은 싱가포르(`sin1`)로 DB와 같은 곳에 둔다. `NODE_ENV=production`으로 실행하므로 개발용 로그인과 Secure 끄기는 켜지지 않는다
- **DB**: Neon Free, AWS 싱가포르, PostgreSQL 18. 서버는 Neon의 연결 풀러 주소로 접속한다
- **배포 흐름**: GitHub의 `main`에 들어오면 배포한다. DB 마이그레이션은 서버의 `main` 배포에서만 실행하고, 브랜치 미리보기는 웹만 만든다(브랜치 미리보기의 웹도 `main`의 서버와 DB를 쓴다)
- **서버리스와 상시 서버 양쪽에서 도는 코드**: 요청 사이의 상태를 메모리에 두지 않는다. 응답을 보낸 뒤 백그라운드 작업을 돌리지 않는다. 연결을 붙잡는 실시간 알림(WebSocket, SSE)은 서버에 두지 않고, 필요해지면 "바뀌었다"는 신호만 따로 보내고 클라이언트가 동기화 API로 가져오게 한다
- **옮길 때**: 실제 사용자를 받거나 수익 모델이 생기면(Hobby의 비상업용 조건), 또는 실시간 알림이나 백그라운드 작업이 서버에 필요해지면 상시 실행 서버(컨테이너)로 옮긴다. 이때 서버 코드는 바꾸지 않고 진입점과 배포 설정만 바꾼다

## 검토한 대안

- **Railway(싱가포르)에 컨테이너와 PostgreSQL**: 상시 서버라 서버리스 제약이 없고 혼자 운영하기 쉽다 — 체험 크레딧 뒤에는 월 최소 $5가 든다
- **Fly.io(도쿄) + Neon**: 한국에서 가장 가깝다 — 무료 등급이 없다
- **Render 무료 + Neon**: 무료이고 상시 서버 구조 그대로다 — 15분 쉬면 잠들고 깨는 데 1분쯤 걸려 써 보기에 불편하다
- **Cloudflare(Workers, Containers)**: NestJS와 Express가 Workers에서 그대로 돌지 않고, Containers는 유료 요금제에 DB 연결 장치까지 조합해야 한다
- **서버가 웹 파일도 내보내는 한 프로세스, 또는 리버스 프록시(Caddy) 앞단**: 상시 서버라면 쓸 방식이다. Vercel에서는 플랫폼의 rewrite가 같은 역할을 한다
- **내 컴퓨터를 터널로 공개(Cloudflare Tunnel)**: 무료지만 컴퓨터가 켜져 있을 때만 쓸 수 있다
