# ADR-0004: 태그와 이어진 기도의 모델

- **상태**: Accepted
- **날짜**: 2026-10-18
- **대체하는 것**: 없음
- **관련**: 개인 기록 모델, 나눔, 모아 보기와 검색

## 요약

태그는 노트와 기도제목 둘 다에 붙인다. 저장하는 태그는 직접 붙인 것뿐이고, 검색과 모아 보기에서는 상속을 계산한다(기도제목 = 자기 태그 + 노트의 태그 + 이어진 기도의 태그). 이어진 기도는 이름과 자체 태그가 없는 "같은 기도의 묶음"으로 남기고, 처음에는 기도제목이 공유하는 식별자로만 표현한다. 태그는 나눔에 복사하지 않는다.

## 맥락

요구사항에는 태그로 모아 보기가 있었지만, 개인 기록 모델의 노트와 기도제목에는 태그 속성이 없었다.
노트의 태그는 쓴 맥락(새벽기도, 청년부 나눔용)이고 기도제목의 태그는 기도의 주제(가족, 건강)라 뜻이 다르다. 쓰는 순간에 정리를 강요하지 않는다는 전제(ADR-0001) 아래에서, 기도제목마다 태그를 다시 붙이게 하지 않으려 했다.
이어진 기도가 태그와 비슷해 보여 꼭 필요한지도 함께 검토했다.

## 결정

- **태그**는 사용자마다 따로 있는 분류 이름이고, 노트와 기도제목에 붙인다
- **상속은 계산이다.** 저장은 노트와 기도제목의 자기 태그만 한다
  - 기도제목의 태그(검색할 때) = 자기 태그 + 노트의 태그 + 이어진 기도의 태그
  - 이어진 기도의 태그 = 속한 기도제목들의 자기 태그를 합친 것. 노트의 태그는 빼서 쓴 맥락이 묶음의 주제로 번지지 않게 한다
  - 그래서 "오늘도 기도"로 이어 쓸 때 태그를 복사하지 않아도 같은 묶음의 태그로 찾힌다
- **이어진 기도**는 같은 기도를 이어 온 기도제목들의 묶음이다. 이름과 자체 태그가 없고 사용자가 만들지 않는다. 한 기도의 타임라인으로 조회한다. 처음에는 기도제목이 공유하는 식별자로만 표현하고, 묶음 자체의 속성(응답 표시 등)이 필요해지면 별도 기록을 둔다
- **나눔에는 태그를 복사하지 않는다.** 태그는 개인적인 정리 수단이다

## 검토한 대안

- **태그를 기도제목에만**: 모델이 단순하지만, 노트 단위의 맥락을 표현할 수 없고 목록 전체에 같은 태그를 붙이려면 하나씩 붙여야 한다
- **노트의 태그를 기도제목에 실제로 복사**: 검색이 단순하지만, 노트에서 태그를 떼도 기도제목에 남아 어긋나고 "실제로 붙는 것"과 "상속된 것"을 구분할 수 없다
- **이어 쓸 때 태그를 복사**: 직관적이지만 같은 묶음 안에서 태그가 어긋나기 쉽다. 묶음의 태그를 상속하면 복사가 필요 없다
- **이어진 기도를 없애고 제목 검색이나 태그로 대신**: 개념이 하나 줄지만, 제목이 바뀌면("어머니 수술" → "어머니 회복") 끊기고, 기도마다 태그를 만들면 태그가 분류 수단으로 쓸모를 잃는다. 연결, 나누기, 합치기와 응답 표시도 둘 곳이 없어진다
- **태그를 나눔에 복사**: 소그룹이 주제로 찾기 쉬워지지만, "힘든 일" 같은 개인 태그가 다른 사람에게 보인다
