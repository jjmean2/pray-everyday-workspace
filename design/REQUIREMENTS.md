# 요구사항: 쌓이는 기도 (시스템 전체)

현재 유효한 요구사항만 둔다. 폐기되거나 대체된 항목은 [archive/requirements.md](archive/requirements.md)로 옮긴다.

- **상태**: `제안` / `확정` / `구현됨` / `보류`
- **출처**: `사용자 요청` / `직접 결정` / `사용 중 발견`
- **설계 분류**: `미분석` / `적합` / `확장` / `재설계`. 새로 추가하거나 고친 항목은 `미분석`으로 둔다
- **관련 결정**: 이 요구사항이 기대는 `D-ID`
