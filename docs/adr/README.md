# 설계 결정 기록 (ADR)

중요한 설계 결정마다 파일 하나를 만든다. 파일명은 `NNNN-짧은-제목.md`, 양식은 [0000-template.md](0000-template.md)를 따른다.

- **Proposed**: Agent나 사람이 제안했고 결정을 기다린다
- **Accepted**: 현재 유효하다
- **Superseded by ADR-NNNN**: 다른 결정으로 대체됐다. 지우지 않고 남긴다
- **Rejected**: 검토했지만 채택하지 않았다. 같은 제안이 반복되지 않도록 남긴다

가장 중요한 부분은 "전제한 가정", "수용하지 못하는 것", "재검토 트리거"다.
새 요구사항이 들어오면 Agent는 이 세 부분과 비교해서 재설계 여부를 판단한다.
