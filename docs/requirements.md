# 요구사항

요구사항은 삭제하지 않고 상태를 바꾼다. 변경 이력이 설계 판단의 근거가 된다.

- **상태**: `제안` → `확정` → `구현됨` / `보류` / `폐기`
- **출처**: `사용자 요청` / `직접 결정` / `사용 중 발견`
- **설계 분류**: 영향 분석 결과 (`적합` / `확장` / `재설계`)와 관련 ADR

| ID | 요구사항 | 상태 | 출처 | 설계 분류 | 비고 |
|---|---|---|---|---|---|
| R-001 | (예시) 매일 기도 여부를 기록할 수 있다 | 제안 | 직접 결정 | - | |
